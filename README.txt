Experience Reflection Recorder

Open:
  Double-click open-essay-recorder.bat
  Or open index.html in a browser.

Main structure:
  ## A Summary of Experience and Reflections
  ### Algorithm / Software / Mechanics / Circuit / Writing / Custom
  - Project:
  - Problem:
  - Cause:
  - Solution:
  - Takeaway:
  - Time:

Notes:
  Use Project to classify records by project name.
  Use Groups to classify the source of the issue, such as Algorithm or Circuit.
  Use Time for the time spent solving the problem, such as 45m, 2h, 1.5h, or 90min.
  Sort by Time shortest or Time longest to compare records by duration.
  Data is saved in this browser's local storage.
  Export TXT downloads a text file directly.
  Export PDF opens a print preview. Choose "Save as PDF" in the print dialog.
  Backup JSON can save all local data for later import.
  The layout is responsive for phone-sized screens.
  If you open it on a different phone or browser, that browser will have its own local data.
